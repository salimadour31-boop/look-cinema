# Look Cinema

Outil gratuit dans le navigateur pour appliquer des looks cinématiques (Teal & Orange, Noir, Vintage, Sci-Fi, Pastel, Bleach Bypass) sur vos images.

## Démo

[https://salimadour31-boop.github.io/look-cinema/](https://salimadour31-boop.github.io/look-cinema/)

## Usage

1. Ouvrez la page.
2. Chargez une image (JPEG, PNG…).
3. Choisissez un look et réglez l'intensité.
4. Exportez le résultat en PNG.

Tout le traitement se fait localement — aucune image n'est envoyée sur un serveur.

## Fonctionnalités

- Looks cinématiques prédéfinis
- Intensité réglable
- Export PNG
- Interface responsive
- Multilingue : français, anglais, taqbaylit (ⵜⴰⵇⴱⴰⵊⵍⵉⵊⵜ)
- Thème sombre
